3D 辅助角色设计为什么是趋势？从建模辅助到美宣成图的完整流程
过去角色设计大多靠二维手绘：画草图、出三视图、上色、画美宣。现在越来越多设计团队把 3D 引入前期流程，用模型辅助设计、用渲染输出美宣。原因不复杂：3D 能提前暴露结构问题、保证多角度一致、方便快速迭代，还能直接产出可用于宣传的成图。下面从趋势原因到完整流程拆解。

为什么 3D 辅助角色设计成为趋势
第一，多角度一致性。二维设计只画正面时，侧面和背面往往靠猜，建模阶段才发现结构不成立。3D 辅助可以在设计阶段就转着看，肩甲怎么连接、披风从哪里起、武器怎么挂，一目了然。

第二，迭代成本低。二维改一个角度要重画，3D 改比例、换配色、调配件可以快速出多版对比。设计师能在短时间内试多种剪影和配色方案，决策更有依据。

第三，直接产出美宣素材。3D 模型加材质灯光渲染，可以输出高质量展示图，减少“设计图到美宣图”的二次转译损耗。风格化渲染还能兼顾手绘质感，让成图更接近最终宣传需求。

第四，方便 downstream 协作。模型、UV、材质分区提前做好，后续绑定、动画、特效环节衔接更顺，减少返工。

完整流程：从建模辅助到美宣成图
第一步：定角色语言与参考。 先写关键词：性格、职业、主形状、主色、记忆点。收集形状、色彩、光影三类参考，明确风格是写实、风格化还是三渲二。角色语言越清楚，后面越不容易反复推翻。

第二步：草图与三视图。 先画剪影检查头身比、肩宽、重心和辨识度，再补正、侧、背三个角度的简图，标出关节连接、服装层次、武器挂点和材质分区。能在纸上改的，不要留到三维里返工。

第三步：灰模搭比例。 用基本体摆出整体剪影，检查比例和透视。灰模阶段只解决大块面，不碰细节。转着看、摆几个动作，确认剪影在各个角度都成立。

第四步：中模说结构。 细化装甲厚度、布料分层、关节连接和倒角关系。硬表面块面要清楚，软性部位布褶走向要合理。这个阶段就要做材质分区和零件命名，为后面 UV 和贴图铺路。

第五步：材质与色彩方案。 先做基础分区：金属、布料、皮肤、发光件。再按设计语言调色阶和高光形状。风格化角色不必追求真实反射，用硬边高光和暗部色块就能表达。配色定主色、辅助色、点缀色，保持统一。

第六步：灯光与相机。 用主光突出主体，补光交代结构，边缘光分离角色和背景。相机提前定展示角度：近景看脸部，中景看剪影，远景看整体色块。背景保持干净，避免抢主体。

第七步：渲染输出美宣成图。 先小图检查剪影、色彩和材质，再提高渲染尺寸。输出后可做轻微调色和构图裁剪，但不要靠后期补救色阶和结构问题。需要多版方案时，固定相机和灯光，只改配色或配件，方便对比。

第八步：复盘与迭代。 检查哪一步最耗时、哪个设计在三维中被证明不可行、下次要简化什么。每版只改一个核心问题，避免同时改所有东西。

新手要注意的坑
不要一上来就抠细节，灰模比例没定就加螺丝和花纹；不要只做一个角度，转着看才发现穿模；不要材质堆太满，风格化要克制；不要忽略性能，面数和贴图尺寸要控制。

3D 辅助角色设计的价值，不是替代手绘，而是把设计决策提前到可验证的三维空间里：先定语言，再搭灰模，中模说结构，材质定风格，灯光出成图，最后复盘迭代。流程跑通，设计效率和成图质量都会明显提升。
